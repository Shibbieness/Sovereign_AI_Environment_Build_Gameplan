# PORT: VUP versioning + attribution — one page

VUP: v[n]u[n]p[n]. p = modification; u = consolidation (p's accumulate into u);
v = architectural (u's accumulate into v). Not semver. Flavored artifacts use VUP.
Vanilla dist/ uses plain semver (scrub rule S2).

Attribution: collaborative flavored artifacts end with
—Shibbieness
—Claude
No authorship declarations in prose. Vanilla products carry a normal byline per
the product's hands_queue-confirmed choice (real name / Shibbieness / M MAOU LLC)
and a license (default MIT tools, CC-BY art).
