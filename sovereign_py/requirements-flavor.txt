# Minimum dependencies for the Vanilla Core flavor adapter (vanilla_flavor.py).
#
# REQUIRED, not optional. flask and sqlalchemy are needed for the adapter to
# work at all: core/module_path_bridge.py imports server/enhanced_routes.py
# while installing aliases, so a missing flask fails the whole bridge. The
# adapter's test suite goes from 2 failures + 11 errors to 19/19 purely by
# installing this file. `--capability status` now names any missing required
# package in one sentence and stops, instead of reporting on the optional
# stack while the mandatory floor is absent.
#
# The heavy ML stack below (chromadb, sentence-transformers, scikit-learn,
# torch) is genuinely optional and does degrade gracefully; status reports
# which of those resolved.
#
# INSTALL NOTE — Debian/Ubuntu images: pip may refuse with
#   "Cannot uninstall blinker x.y.z, RECORD file not found. Hint: The package
#    was installed by debian."
# flask depends on blinker, and the distro-managed copy has no pip metadata
# to uninstall. Either use a virtualenv (preferred), or:
#   pip install --ignore-installed blinker -r requirements-flavor.txt
flask
flask-cors
flask-socketio
sqlalchemy
python-dotenv
markdown
PyPDF2
python-magic
watchdog
numpy
